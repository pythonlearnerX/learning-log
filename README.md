# learning-log

> 每天 3 行。不为好看，只为**证明我没有停**，以及在断掉之后能 10 分钟接上。

## 规则

1. 每月一个文件：`2026-11.md`、`2026-12.md` …
2. 每天一条，3 行就够：**做了什么 / 卡在哪 / 明天第一件事**
3. 当天没写，第二天补一句「昨日空窗，原因：」——不美化，不删
4. 每周日加一条「本周复盘」，每月末加一条「本月复盘」

## 为什么值得做

- 面试官点进你的 GitHub，看到 300 天连续记录，比任何自我介绍都有说服力
- 卡住的时候翻上周的记录，能立刻知道自己走到哪了
- 年底回看，能发现自己真正的时间花在哪
